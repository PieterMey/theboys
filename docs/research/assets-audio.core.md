# assets-audio

## Executive summary
Everything the MVP needs can be fetched by script tonight, mostly without API keys. Poly Haven (CC0) has a REST API at api.polyhaven.com (/assets, /files/{id}, /info/{id} and a new semantic /search) with 865 textures, 521 models and 997 HDRIs on direct dl.polyhaven.org URLs. ambientCG (CC0, v3 API at ambientcg.com/api/v3/assets, zips at /get?file=ID_2K-JPG.zip) fills the gaps: wallpaper, painted-metal doors and lockers, grates, chain-link and animated leak decals. I checked live that a 25-prop horror shortlist exists: shelves, crates, barrels, beds, wheelchair, desks, cabinets, fluorescent lamps, fuse box, generator, radio, flashlight, gas mask. It is about 55 MB of raw 1K glTF. I also checked 25 tiling materials and 9 dark HDRIs. Poly Haven has no lockers, metal doors, gurneys, mannequins or modular architecture, so those must be built procedurally using the metal and paint textures. For characters, the Quaternius CC0 sets are the only scriptable option where every pack shares one rig. The free UAL2 Standard (a direct OpenGameArt URL) ships a mannequin of about 13.7k triangles on a 65-joint UE-style skeleton, plus 43 clips: zombie walk/idle/scratch, carry, lay-to-idle (revive) and lantern idle. UAL1 Standard adds crouch, torch idle, interact, kneeling fix, push, pick up and death. However, the OpenGameArt copy of UAL1 uses the old Rigify 'DEF-' rig. Get UAL1 v3 and Universal Base Characters from itch.io instead, through the free 'No thanks' flow (Playwright, or 2 minutes of clicking). Build the creator on that shared skeleton: color and material slots, bone-scale body sliders, accessories attached to bones (gas mask, hats, headlamp), and a skinned coverall 'shell'. Skip morph targets, Mixamo (no API, login required, maintenance mode), VRM (anime look) and Ready Player Me (its domain no longer resolves). Tonight's monsters should reuse the same rig: a mannequin that moves only when nobody is looking, an elongated stalker, and a player-mimic. Paid AI 3D generation is optional. Tripo is cheapest for creatures ($0.01/credit; image-to-3D 30 credits; auto-rig 25 credits across 7 rig types; retarget 10 per clip). Meshy offers an MCP server, but its rigging is humanoid-only and API access needs a paid plan. Locally, TRELLIS.2 (MIT, needs 24 GB VRAM, only tested on Linux) suits the RTX 5090. Avoid Hunyuan3D if the user is in the EU or UK: its license excludes those territories, and 3.x has no open weights. Pipeline: @gltf-transform/cli 4.5.1 with meshopt (I measured the UAL2 GLB going from 8.06 to 2.0 MB) plus KTX2 (UASTC for normal/ARM maps, ETC1S for albedo; needs KTX-Software 4.4.2 or the ktx2-encoder WASM fallback). Use 1K props and 2K surfaces, keep the first download under 150 MB, and load with three@0.186.1 GLTFLoader, KTX2Loader and MeshoptDecoder. Audio: Kenney Impact/RPG and the rubberduck OpenGameArt packs (all CC0), the Little Robot horror library (CC-BY 3.0) and Freesound CC0 previews (a token is enough; originals need OAuth2). Synthesize drones, heartbeat, radio static, hum, reverb and occlusion procedurally in Web Audio. Skip Sonniss tonight (downloads behind a Cloudflare challenge, multi-GB, AI-training ban). Recommendation: one build-time Node fetch-and-optimize script driven by a JSON manifest of the checked IDs below, outputs self-hosted (no attribution obligations except the CC-BY audio and music). Ask the user only for a free Freesound API key now, plus optionally a Tripo or Meshy key and a one-time itch.io download.

## Risks
- Quaternius UBC, UAL1 v3 and outfits are on itch.io behind a JS download flow; a curl replay of /file/{upload_id} returned 'invalid key' => Automate with Playwright (purchase page, then 'No thanks', then the Download button with a download event) or ask the user to click 3 downloads. Meanwhile, start with UAL2 Standard plus the mannequins, which have direct OpenGameArt URLs.
- Rig mismatch: the OpenGameArt UAL1 copy uses Rigify 'DEF-*' bones while UAL2/UBC use the 65-joint UE naming, so clips silently fail to bind => Prefer itch UAL1 v3; otherwise retarget with SkeletonUtils.retargetClip and a name map (DEF-hips to pelvis, DEF-spine.001 to spine_01, ...). Add a load-time check that logs any clip track whose bone name is missing.
- Stylized Quaternius characters clash with photoreal Poly Haven props => Dress characters in suits, masks and helmets with PBR fabric and metal, keep them mostly in darkness and lit by flashlights, add film grain. Later, swap in AI-generated or MPFB2 realistic bodies on the same rig.
- KTX2 tooling: gltf-transform etc1s/uastc need KTX-Software's 'ktx' on PATH, and the installer needs admin => Use the ktx2-encoder 0.6.0 WASM transform (with sharp) inside a Node script, or gltfpack 1.3's built-in BasisU (-tc). Last resort: --texture-compress webp, accepting higher VRAM use, plus a 1K texture cap.
- Asset bandwidth: friends pull 100+ MB through the host's home uplink and the tunnel; four players at once could take minutes => Compress aggressively (meshopt + KTX2, 1K props), use hashed filenames with immutable caching and a service-worker cache, stream after the lobby, or push static assets to a CDN (coordinate with the infra researcher).
- optimize defaults (join, palette, flatten, simplify) merge materials and alter skinned hierarchies, breaking character color slots and accessory bones => Use separate command presets for characters and recolorable props (--join false --palette false --flatten false --simplify false) and check with gltf-transform inspect plus a screenshot test.
- Hunyuan3D 2.1 license is void in the EU, UK and South Korea, including use of its outputs, and the user may be in the EU (name suggests Dutch, Belgian or South African) => Default to TRELLIS.2 (MIT) or the Tripo/Meshy APIs. Only use Hunyuan if the user confirms they are outside the excluded territories.
- Meshy deletes results after 3 days and its rigging is humanoid-only; non-humanoid AI monsters may come back badly rigged => Download immediately in the same script. Use Tripo with rig_type for creatures, or UniRig (MIT) locally. Review rigs in a three.js preview page with screenshots.
- Freesound originals need OAuth2, and API commercial use is negotiated => Use CC0 preview-hq-ogg (about 192 kbps) for SFX tonight. For any later commercial release, re-download the originals via OAuth2 and keep license metadata in credits.json.
- Sonniss downloads are blocked to scripts by a Cloudflare challenge, are multi-GB, and ban raw redistribution and AI training => Skip it tonight. Later the user downloads 1 or 2 parts manually or via torrent; curate locally and ship only the processed clips inside the game.
- Remote WebRTC audio routed through Web Audio PannerNodes can be silent in Chrome unless also attached to a media element, and echo cancellation may not cover Web Audio playback (not verified this session) => Attach each stream to a muted Audio element as a workaround, test on Chrome 154 and Firefox with two machines tonight, and require or recommend headsets.
- Decoded audio memory blowup (float32 PCM, about 23 MB per stereo minute) and MP3 loop gaps => Mono Opus one-shots, short loops, stream long ambiences via a media element, never MP3 for loops.
- Third-party pricing claims (Rodin, fal Hunyuan v3, ElevenLabs credits per second vs per generation) could not be fully verified; the WebSearch budget ran out mid-research => Treat them as estimates and recheck on the vendors' pricing pages before buying credits.

## Decision-critical claims
- Poly Haven and ambientCG assets are CC0 and fully scriptable without API keys (Poly Haven only needs a unique User-Agent). Self-hosting the downloaded files carries no attribution requirement; the 'Powered by Poly Haven' credit applies only when the live API is used at runtime.
- Poly Haven lacks lockers, metal doors, gurneys, mannequins and modular architecture, so those must be procedural (or AI-generated later).
- The free UAL2 Standard (direct OpenGameArt URL) contains a 65-joint UE-style mannequin rig plus 43 clips including zombie locomotion, carry and revive. The free UAL1 has crouch, torch idle, interact and fix clips, but its OpenGameArt copy uses a different DEF-* rig; the itch.io v2.0+ copy matches UAL2/UBC naming.
- Universal Base Characters and UAL1 v3 can only be fetched through itch.io's browser flow (Playwright or a manual click), not plain curl.
- Hunyuan3D 2.1's license excludes the EU, UK and South Korea (including outputs), and Hunyuan3D 2.5/3.x have no open weights; TRELLIS.2-4B is MIT but tested only on Linux with 24 GB+ VRAM.
- Meshy auto-rigging is humanoid-only, its API needs a paid plan, and results expire after 3 days. Tripo rigs 7 creature classes at $0.25 per rig ($0.01 per credit).
- gltf-transform's KTX2 commands depend on the external KTX-Software 'ktx' CLI (4.4.2 stable); the ktx2-encoder WASM and gltfpack built-in BasisU are no-install fallbacks.
- three@0.186.1 KTX2Loader.detectSupport(renderer) works with WebGPURenderer after await renderer.init(), and GLTFLoader decodes both EXT_ and KHR_meshopt_compression.
- Freesound previews (about 192 kbps OGG) are reachable with a simple token; downloading originals requires OAuth2.
