- Poly Haven client: send 'User-Agent: theboys-horror/0.1' on every call. To list: GET https://api.polyhaven.com/assets?t=models|textures|hdris (optional &c=category). To discover: GET https://api.polyhaven.com/search?q=hospital%20equipment&t=models&limit=20 returns [{slug,score}]. To download: GET /files/{id}.
- Poly Haven model download: take files.gltf['1k'].gltf.url and every files.gltf['1k'].gltf.include[relPath].url. Save each include at its relPath next to the .gltf (e.g. 'textures/x_diff_1k.jpg' and 'x.bin'; the .bin is served from .../gltf/8k/... but its relPath is the file name). Verify md5, then run 'npx gltf-transform copy x.gltf x.glb'.
- Poly Haven tiling materials: files.Diffuse['2k'].jpg.url, files.nor_gl['2k'].png.url (use PNG as UASTC input to avoid JPEG generation loss), files.arm['2k'].jpg.url. ARM channels are R=AO, G=roughness, B=metalness, so set aoMap = roughnessMap = metalnessMap = the arm texture. Always use nor_gl/NormalGL, never nor_dx (three.js and glTF use the OpenGL convention).
- Poly Haven glTF fix-up script (gltf-transform API): for (const m of doc.getRoot().listMaterials()) { const t = m.getMetallicRoughnessTexture(); if (t) m.setOcclusionTexture(t); m.setDoubleSided(false); }. Keep doubleSided on thin props such as shelves and signs; check with a screenshot.

- Character runtime: load the base GLB once; per player use SkeletonUtils.clone(gltf.scene) and one THREE.AnimationMixer; clips from the UAL GLBs bind by bone name. Attach rigid accessories with skeleton.getBoneByName('Head').add(mask) and hand_r for flashlight/radio; the headlamp is a SpotLight on Head with castShadow. For body sliders, scale root (height 0.92 to 1.08), clavicle_l/r (shoulders) and spine_02/03 x/z (bulk), and recompute nothing else.
- Character creator config JSON (synced over the network): {base:'m'|'f', height, shoulders, bulk, suitColor, accentColor, visorTint, head:'none'|'old_gas_mask'|'helmet'|'fishermans_hat', backpack, hairId, hairColor, nameTag}. Coverall shell: clone the body SkinnedMesh with a MeshPhysicalNodeMaterial (sheen for fabric), positionNode = positionLocal.add(normalLocal.mul(0.01)), and mask out head and hands by dominant skinIndex. Hi-vis strips use emissive * fresnel.
- Never run optimize with defaults on characters or recolorable props. Use: gltf-transform optimize in.glb out.glb --compress meshopt --join false --palette false --flatten false --simplify false --instance false --texture-compress ktx2 --texture-size 2048. join and palette merge materials and destroy color slots; flatten and simplify can disturb skinned hierarchies.
- Static props: gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress ktx2 --texture-size 1024. Finer control: gltf-transform uastc in.glb a.glb --slots "{normalTexture,metallicRoughnessTexture,occlusionTexture}" --level 2 --rdo --zstd 18 && gltf-transform etc1s a.glb b.glb --slots "{baseColorTexture,emissiveTexture}" --quality 192 && gltf-transform meshopt b.glb out.glb --level high. Validate the slot-glob behavior on one file first. If ktx cannot be installed, use --texture-compress webp: smaller download, but full RGBA8 in VRAM.
- Standalone tiling textures with KTX-Software 4.4.x: ktx create --format R8G8B8_SRGB --encode basis-lz --qlevel 192 --generate-mipmap diff.png diff.ktx2, and ktx create --format R8G8B8_UNORM --encode uastc --uastc-quality 2 --zstd 18 --generate-mipmap nor_gl.png nor.ktx2 (do the same for arm). The v5 docs name the codec 'uastc-ldr-4x4'. Skip --normal-mode: two-channel normals need a custom Z reconstruction in TSL. Set texture.colorSpace = THREE.SRGBColorSpace only on albedo, and wrapS = wrapT = RepeatWrapping.
- Runtime loading: import * as THREE from 'three/webgpu'; const r = new THREE.WebGPURenderer(); await r.init(); const ktx2 = new KTX2Loader().setTranscoderPath('/libs/basis/').detectSupport(r); const loader = new GLTFLoader().setKTX2Loader(ktx2).setMeshoptDecoder(MeshoptDecoder). Copy node_modules/three/examples/jsm/libs/basis/basis_transcoder.{js,wasm} to public/libs/basis/. Use HDRLoader (not the deprecated RGBELoader) plus PMREMGenerator, with envMapIntensity of about 0.05 to 0.2 indoors.
- Procedural architecture: emit world-space UVs per axis-aligned face (u = x or z, v = y, both divided by tileSize), so each material needs one sample. Reserve TSL triplanarTexture (3 samples) for rubble and organic meshes. Place ambientCG decals with DecalGeometry and grime with mx_noise_float masks.
- VRAM math (mips x4/3): 2048^2 RGBA8 = 21.3 MiB; BC7 from UASTC = 5.3 MiB; BC1 from ETC1S = 2.7 MiB. 1024^2: 5.3 / 1.3 / 0.67 MiB. One 2K material (ETC1S albedo + UASTC normal + UASTC ARM) is about 13.3 MiB compressed versus 64 MiB as JPG; 20 materials are about 270 MiB at 2K or about 70 MiB at 1K. 30 props at 1K with 3 maps are about 120 MiB. HDR render targets: 2560x1440 RGBA16F is about 29.5 MB each (about 300 MB for 10); at 4K about 66 MB each. Target at most 1 to 1.5 GB total on 6 to 8 GB cards, plus a 1K-only low preset.
- Download budget: aim for at most about 120 to 150 MB on first load and stream level props after the lobby. Use content-hashed filenames with 'Cache-Control: public, max-age=31536000, immutable' and gzip or brotli for .glb (meshopt output compresses further; KTX2 is already zstd-compressed). Assets travel over the host's home uplink through the tunnel, so measure this or put static assets on a CDN.
- Audio conversion: ffmpeg -y -i in.wav -af "silenceremove=start_periods=1:start_threshold=-60dB,loudnorm=I=-20:TP=-2:LRA=11" -ac 1 -ar 48000 -c:a libopus -b:a 96k out.ogg for spatialized one-shots (PannerNode is mono-in). For stereo ambience use -ac 2 -b:a 128k. Don't use MP3 for loops: encoder padding causes audible gaps.
- Decoded AudioBuffers are float32: 48000 Hz x 2 ch x 4 B = 384 KB/s, so a 60 s stereo loop is about 23 MB of RAM. Keep one-shots short and decode them; stream long ambiences or music through an HTMLMediaElement into a MediaElementAudioSourceNode.
- Freesound fetch (needs the user's key): GET https://freesound.org/apiv2/search/?query=door%20creak&filter=license:%22Creative%20Commons%200%22%20duration:%5B0.3%20TO%2012%5D&fields=id,name,username,license,duration,previews,avg_rating,num_downloads&sort=rating_desc&page_size=30&token=$FREESOUND_API_KEY, then download previews['preview-hq-ogg']. For originals, do a one-time OAuth2 (the user approves in a browser), then GET /apiv2/sounds/{id}/download/ with 'Authorization: Bearer <token>' (30/min, 500/day). Gap queries: fluorescent hum, ventilation hum, radio static, walkie talkie squelch, flashlight click, breaker switch, generator start, metal door slam, elevator, dripping water, wind interior, whisper.
- Kenney and OpenGameArt direct URLs: https://kenney.nl/media/pages/assets/impact-sounds/87b4ddecda-1677589768/kenney_impact-sounds.zip ; .../rpg-audio/8e99002d76-1677590336/kenney_rpg-audio.zip ; .../sci-fi-sounds/6b296f9ecf-1677589334/kenney_sci-fi-sounds.zip ; .../interface-sounds/fa43c1dd4d-1677589452/kenney_interface-sounds.zip ; https://opengameart.org/sites/default/files/80-CC0-creature-SFX_0.zip ; .../100-CC0-SFX_0.zip ; .../sfx_breaking_and_falling.zip ; '.../Horror%20Sound%20Library.zip' (CC-BY 3.0). Kenney URLs embed a hash, so re-scrape them from the asset page if one returns 404.
- Procedural drone: 2 sawtooth OscillatorNodes at 41.2 Hz (one detuned +7 cents) plus a 20.6 Hz sine, into a BiquadFilter lowpass (180 Hz, Q 4). A 0.07 Hz LFO through gain 120 modulates the filter frequency. Brown noise through a 400 Hz bandpass sits at -30 dB. Send to a ConvolverNode (3.5 s IR, about 0.4 wet). A master gain follows the 'tension' value 0 to 1 via setTargetAtTime.
- Procedural heartbeat: per beat at time t, a sine whose frequency is set to 110 Hz at t and exponentially ramps to 45 Hz by t+0.09, with gain rising 0 to g in 4 ms and decaying exponentially to 0.001 by t+0.18. Add a second beat at t+0.28 with 0.6*g, then lowpass at 120 Hz. BPM = lerp(60, 150, fear). Use a lookahead scheduler (setInterval 25 ms, schedule 100 ms ahead) on a non-spatial 'body' bus, and duck the ambience 2 to 3 dB per beat.
- Procedural radio static and walkie-talkie: a looping 2 s white-noise AudioBuffer into a bandpass (1.8 kHz, Q 0.8), then a WaveShaper (tanh, k = 8 to 20), then a gain driven by random steps. Voice-over-radio chain: highpass 400 Hz, lowpass 3 kHz, WaveShaper, DynamicsCompressor. Push-to-talk squelch: a 1 kHz sine for 60 ms on press and a 120 ms noise burst on release. Fluorescent hum: 100 Hz + 200 Hz sines (EU mains; 120/240 Hz in the US) gated together with the visual flicker.
- Reverb and occlusion: build a ConvolverNode IR per room size. For each of 2 channels, buffer[i] = (Math.random()*2-1) * Math.pow(1 - i/len, 3), with len = sampleRate * decay (closet 0.4 s, corridor 1.2 s, hall 2.5 s, warehouse 4 s). Per-source occlusion: lowpass cutoff = max(500, 20000 * 0.25^walls) and gain multiplied by 0.7^walls, from nav-grid raycasts and closed doors. Spatialize with PannerNode {panningModel:'HRTF', distanceModel:'inverse', refDistance:1.5, rolloffFactor:1.2, maxDistance:40}, and update positions with setTargetAtTime(x, ctx.currentTime, 0.02).
- Remote WebRTC voice into Web Audio: also attach each remote MediaStream to a muted new Audio() with srcObject = stream and call play() before createMediaStreamSource (a long-standing Chrome workaround; test on Chrome 154). Recommend headsets: echo cancellation may not cover audio played through Web Audio.
- Mimic monster audio (opt-in): run MediaRecorder on each player's local mic (audio/webm;codecs=opus); keep 2 to 4 s segments when AnalyserNode RMS shows speech; upload them to the host session store (memory only, deleted at session end); play them back from the monster's PannerNode with playbackRate 0.97 to 1.0 plus a slight radio EQ.
