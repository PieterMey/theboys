# speech details

## Implementation notes
- STT sidecar install (worked on this host): uv venv .venv --python 3.13 && uv pip install --python .venv/Scripts/python.exe faster-whisper==1.2.1 ctranslate2==4.8.2 nvidia-cublas-cu12 'av==16.1.0' 'onnx-asr[cpu,hub]==0.12.0' numpy soundfile. nvidia-cudnn-cu12 was also installed but is probably unneeded because ctranslate2's Windows wheel bundles cudnn64_9.dll. Set HF_HUB_DISABLE_SYMLINKS_WARNING=1, since Windows without Developer Mode prints a symlink warning and falls back to copying files.
- Windows DLL fix before importing faster_whisper: for each site-packages dir and each sub in (cublas, cuda_nvrtc, cudnn), call os.add_dll_directory(<sp>/nvidia/<sub>/bin) and prepend it to PATH. No CUDA toolkit install is needed.
- WhisperModel('large-v3-turbo', device='cuda', compute_type='float16') resolves to mobiuslabsgmbh/faster-whisper-large-v3-turbo (about 1.6 GB; first load including download took 128 s). Do not use int8 or int8_float16 on the 5090 (INT8 is disabled on sm_120). Load once at startup and run one warm-up transcribe.
- Transcribe call: segments, info = model.transcribe(f32_16k_mono, language='en', beam_size=1, without_timestamps=True, condition_on_previous_text=False, vad_filter=False, hotwords='<ghost name> <player names>'). Consume the generator, then drop segments with no_speech_prob > 0.6, avg_logprob < -1.0, or stock hallucinations ('Thank you.', 'Thanks for watching!'). Other useful params: initial_prompt, no_speech_threshold, hallucination_silence_threshold, multilingual.
- Parakeet fallback: m = onnx_asr.load_model('nemo-parakeet-tdt-0.6b-v3', quantization='int8', providers=['CPUExecutionProvider']); text = m.recognize(f32_16k, sample_rate=16000). Model repo istupakov/parakeet-tdt-0.6b-v3-onnx (int8 encoder 652 MB + decoder 18 MB). onnx-asr also exposes .with_vad() and .with_timestamps().
- Browser capture option A (preferred): an AudioWorkletProcessor keeps a ring buffer at ctx.sampleRate (usually 48k) with 300 ms pre-roll. On push-to-talk release, downsample to 16 kHz Int16 and send one binary WebSocket frame. Sizes: 3 s is 96 KB, 6 s is 192 KB.
- Browser capture option B: new MediaRecorder(micStream, {mimeType}) with mimeType chosen via MediaRecorder.isTypeSupported('audio/webm;codecs=opus'), else 'audio/ogg;codecs=opus'. Call start() on press and stop() on release, then upload the single Blob. The server calls faster_whisper.decode_audio(BytesIO(blob), sampling_rate=16000) (14 ms measured). With a timeslice, only the first chunk carries the container header, so concatenate from the start.
- Hands-free segments and mimic clips: vad.MicVAD.new({model:'v5', getStream: async () => micStream, preSpeechPadMs: 200, minSpeechMs: 400, onSpeechEnd: f32 => upload(f32)}). Self-host baseAssetPath and onnxWASMBasePath assets. Verify option names against docs.vad.ricky0123.com for 0.0.31.
- Put the TTS in a Node worker_thread on the host: const tts = await KokoroTTS.from_pretrained('onnx-community/Kokoro-82M-v1.0-ONNX', {dtype:'fp32', device:'cpu'}); const a = await tts.generate(text, {voice:'bm_george', speed:0.85}). a.audio is a Float32Array and a.sampling_rate is 24000. Post a.audio.buffer as a transferable. from_pretrained accepts only dtype, device and progress_callback, so there is no session_options passthrough.
- For streaming LLM output: const splitter = new TextSplitterStream(); for await (const {text, audio} of tts.stream(splitter)) send(audio). Push Claude's tokens with splitter.push(token) and call splitter.close() at the end. The first sentence arrives after about 0.3 s on CPU fp32.
- Voice line transport: a WebSocket binary frame holding a JSON header {lineId, emitterId, pos:[x,y,z], startAtServerMs, sr:24000} followed by Int16 PCM. The client builds the buffer with const b = ctx.createBuffer(1, n, 24000); b.copyToChannel(f32, 0), which Web Audio resamples automatically. Schedule src.start(ctx.currentTime + (startAtServerMs - estServerNow)/1000) using a ping-derived clock offset so every client hears the line at once (the Mirage approach).
- Native Web Audio ghost chain: AudioBufferSourceNode (detune -400..-700 cents, or playbackRate 0.8) feeds a WaveShaperNode (curve y=(1+k)x/(1+k|x|), k=20-50, oversample '4x'), then a BiquadFilter lowshelf +6 dB at 150 Hz, then an HRTF PannerNode (panningModel 'HRTF', distanceModel 'inverse', refDistance 2, rolloffFactor 1.2) with a ConvolverNode room send. Add a lowpass at 800-1500 Hz when the ghost is occluded by walls. Update positions with positionX.setTargetAtTime each frame.
- Ring modulator: const rm = new GainNode(ctx, {gain: 0}); const osc = new OscillatorNode(ctx, {frequency: 45}); osc.connect(rm.gain); osc.start(); voice.connect(rm).connect(wet). Mix wet at about 25%. Add an octave-down doubler (second source with detune -1200, -12 dB).
- Reverse-reverb swell, rendered offline per line: reverse the buffer's samples, render it through a ConvolverNode in an OfflineAudioContext(1, len + irLen, sr), reverse the result back, and play it starting irDuration seconds before the dry voice. The IR can be procedural: 2.5-4 s of white noise times exp(-t/0.8), stereo-decorrelated. No asset file needed.
- Whisper layer: render the same text with Kokoro voice af_nicole (the soft 'headphones' voice), pass it through a highpass at 1.5-2 kHz, delay 30-80 ms, mix at -6 dB and pan slightly off-axis. Alternative: a noise vocoder, where an AudioWorklet envelope follower on the voice drives the gain of bandpassed white noise.
- Formant-aware pitch shift (optional, better quality): import SignalsmithStretch from 'signalsmith-stretch'; const st = await SignalsmithStretch(ctx); src.connect(st); st.connect(chainIn); st.schedule({semitones: -5, formantSemitones: -8, formantCompensation: false}); st.start(). Lowering formants more than pitch gives a big-creature sound; keeping formants gives an uncanny one. Pre-schedule by st.latency() (about 0.1 s). Quick, more artefact-prone alternative: new Tone.PitchShift(-7) from tone 15.1.22.
- Spirit-box chop: route the line through a bandpass at 400-3000 Hz and WaveShaper, then a GainNode toggled with setValueAtTime every 80-250 ms (random on/off), over a looped white-noise bed. Start the static on push-to-talk release to hide the STT + LLM + TTS time.
- Mimic store on the host: Map<playerId, {id, pcm16, text, durMs, t}[]>, about 40 clips per player, FIFO eviction, never written to disk, cleared when the session ends. Collect only from players with consent=true from the lobby toggle. STT labels each clip asynchronously (50 ms on GPU) so the AI director can pick by meaning ('help', 'over here', names). Play back with detune -50..-150 cents, a slight bandpass and HRTF at the monster's position.
- 'Ghost hears you' without sending audio: an AnalyserNode (fftSize 1024) on the local mic computes RMS dBFS every 100 ms; send {dB} to the server only when above about -45 dBFS. Server-side always-on STT of VAD segments (to catch the ghost's name being spoken) costs about 50 ms per segment, so it is affordable for 4 players.
- Secure context: getUserMedia, AudioWorklet and SpeechRecognition need HTTPS or localhost, so friends must reach the game through the tunnel's HTTPS URL. Call ctx.resume() inside a user gesture (the click that joins the lobby).
- If Web Speech is ever used as an optional client mode: const R = window.SpeechRecognition || window.webkitSpeechRecognition. Check await SpeechRecognition.available({langs:['en-US'], processLocally:true}) and call install() if the result is 'downloadable'. Then r.processLocally = true; r.phrases = [new SpeechRecognitionPhrase('<ghost name>', 5.0)] (Chrome 142+); r.start(micTrack) (Chrome 135+). Firefox Release will not have R.
- Python TTS options on Blackwell, if needed later: chatterbox-tts pins torch==2.6.0, so install torch==2.14.1 with --index-url https://download.pytorch.org/whl/cu130 and override the pin (for example uv pip install chatterbox-tts --override overrides.txt containing torch>=2.7 and torchaudio>=2.7). This is untested, so check API breakage with transformers==5.2.0. Docker alternative: docker run --gpus all -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-gpu:latest-cu128.

## Key facts
- (high) SpeechRecognition support per BCD: Chrome 33+ (webkit prefix); start(MediaStreamTrack) Chrome 135; processLocally, available() and install() Chrome 139; phrases (contextual biasing) Chrome 142; Edge mirrors Chrome; Firefox only 'preview' (Nightly); Safari 14.1+ webkit-prefixed with no on-device API. [https://raw.githubusercontent.com/mdn/browser-compat-data/main/api/SpeechRecognition.json]
- (high) Chrome's default recognition sends audio to a Google web service. On-device mode is opt-in and needs per-language packs of about 60 MB, initially on Windows, Mac and Linux. [https://groups.google.com/a/chromium.org/g/blink-dev/c/VNOok2dbmHM/m/TQpe9shjCgAJ]
- (high) Web Speech spec (Draft CG Report, 18 Sep 2026): SpeechRecognitionOptions {langs, processLocally=false, quality: command|dictation|conversation}; AvailabilityStatus is unavailable/downloadable/downloading/available; phrase boost range 0-10; error codes include language-not-supported and phrases-not-supported. [https://webaudio.github.io/web-speech-api/]
- (high) The SpeechSynthesis API gives no way to get synthesised audio as a MediaStream or buffer, so it cannot be fed into Web Audio for spatialisation or distortion. [https://webaudio.github.io/web-speech-api/]
- (high) Edge's local speech recognition model is available only in Canary/Dev 150.0.4076+ behind edge://flags 'Speech Recognition with on-device model'. Languages: en-US, de-DE, it-IT, pt-PT, es-ES, ko-KR. [https://learn.microsoft.com/en-us/microsoft-edge/web-platform/speech-recognition-api]
