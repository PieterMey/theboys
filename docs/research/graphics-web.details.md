## Implementation notes
- Install: npm i three@0.186.1 @dimforge/rapier3d-compat@0.21.0 three-mesh-bvh@0.9.15; dev: vite@8.3.3 @types/three@0.186.0 @playwright/test@1.63.0 pixelmatch@8.0.0. 'three' and 'three/webgpu' share build/three.core.js, so addons importing 'three' do not duplicate core.
- The npm package ships examples/jsm (addons, basis/draco libs) but NOT the example HTML. Have the agent fetch reference files into the repo: https://raw.githubusercontent.com/mrdoob/three.js/r186/examples/<name>.html (webgpu_volume_lighting, webgpu_volume_lighting_traa, webgpu_lights_projector, webgpu_lights_spotlight, webgpu_lights_ies_spotlight, webgpu_postprocessing_ao, webgpu_postprocessing_traa, webgpu_upscaling_taau, webgpu_postprocessing_bloom, webgpu_postprocessing_ca, webgpu_postprocessing_3dlut, webgpu_postprocessing_retro, webgpu_fog_height, webgpu_shadowmap_pointlight, webgpu_postprocessing_ssgi, webgpu_vxgi, webgpu_lightprobes, webgpu_lights_dynamic, webgpu_lights_clustered, webgpu_performance_renderbundle, webgpu_mesh_batch, webgpu_generator_building).
- Renderer init: const adapter = await navigator.gpu?.requestAdapter(); const L = adapter?.limits; renderer = new THREE.WebGPURenderer({ antialias:false, trackTimestamp:true, forceWebGL: url.has('webgl'), requiredLimits: L ? { maxSampledTexturesPerShaderStage: L.maxSampledTexturesPerShaderStage, maxSamplersPerShaderStage: L.maxSamplersPerShaderStage, maxColorAttachmentBytesPerSample: L.maxColorAttachmentBytesPerSample } : undefined }); await renderer.init(). Wrap it in try/catch and retry without requiredLimits. Log renderer.backend.isWebGPUBackend and adapter.info, and show a banner when on WebGL2.
- Renderer state: renderer.shadowMap.enabled = true; renderer.shadowMap.type = THREE.PCFShadowMap; toneMapping = THREE.ACESFilmicToneMapping (or AgX/Neutral, exposure 1-1.5). Then await renderer.compileAsync(scene, camera) behind the loading screen, with every material, the light pool and the post chain already instantiated (same as threejs-punk's warmup.js split compile).
- Flashlight pool sketch: for i<POOL: l = new THREE.ProjectorLight(0xfff1d6, 0, 28, 0.42, 0.7, 2); l.castShadow = true; l.shadow.mapSize.setScalar(res); l.shadow.camera.near = 0.15; l.shadow.camera.far = 28; l.shadow.bias = -0.0004; l.shadow.normalBias = 0.02; l.shadow.radius = 3; l.colorNode = cookieFn; l.layers.enable(10); scene.add(l, l.target). Also create (maxPlayers-POOL) SpotLights with castShadow false. Each frame, sort flashlights by local-first, then in-frustum, then distance, and copy pose/intensity into slots; unused slots get intensity 0. Never change castShadow or the light count.
- Cookie as TSL colorNode (signature Fn(([projectorUV]) => color)): radial hot spot + ring + smudge from mx_fractal_noise_float(projectorUV*k), times a flicker uniform. That costs no texture/sampler binding.
- Texture/sampler budget per fragment shader is 16 on default limits: shadow maps + cookie maps + material maps + env map. Example: 3 material maps (albedo, normal, packed ORM) + env + 8 shadow maps = 12 fits; 8 textured cookies would overflow. Test 8 shadowed lights + the heaviest material in the first hour and watch the console for WebGPU validation errors.
- Volumetric beams, from webgpu_volume_lighting.html: vm = new THREE.VolumeNodeMaterial(); vm.steps = 10; vm.offsetNode = bayer16(screenCoordinate); vm.scatteringNode = Fn(({positionRay}) => texture3D(noise3D, positionRay.mul(s).mod(1), 0).r ...); box mesh over the active chunk on layer 10 only; volPass = pass(scene, camera, {depthBuffer:false}); volPass.setLayers(volLayer); volPass.setResolutionScale(0.25); vm.depthNode = sceneDepth.sample(screenUV); color = scenePass.add(gaussianBlur(volPass, 0.6).mul(intensity)). Cost scales with steps x lights on layer 10.
- Post chain order: prePass (opaque, MRT normal + velocity, set normal texture type UnsignedByte) -> aoPass = ao(prePassDepth, prePassNormal, camera); aoPass.resolutionScale = 0.5; scenePass.contextNode = builtinAOContext(aoPass.getTextureNode().sample(screenUV).r) -> + volumetric -> bloom(node, strength, radius, threshold) -> traa(color, prePassDepth, prePassVelocity, camera) -> film(node, intensity) -> chromaticAberration(node, strength, center, scale) -> vignette(node, intensity, smoothness) from tsl/display/CRT.js -> lut3D(node, lut, size, intensity) via LUTCubeLoader. Assign renderPipeline.outputNode and set needsUpdate = true when the chain changes.
- Fog: scene.fogNode = fog(color(0x06080b), exponentialHeightFogFactor(density, height)) (webgpu_fog_height.html); densityFogFactor or rangeFogFactor are alternatives. Add grain/IGN dithering because 8-bit canvas output bands in dark gradients.
- Quality presets (budgets are estimates, verify with GPU timestamps):
- Low: 0.6 scale + FSR1/TAAU, 2 shadowed flashlights @512, no volumetrics (additive cone mesh instead), no AO, SMAA, grain + vignette; or the Retro mode.
- Medium (RTX 3060/4060 @1080p): 0.85-1.0 scale, TRAA, 4 @1024, volumetric 0.25 res / 8-10 steps, GTAO 0.5, bloom, LUT. Roughly 9-13 ms GPU.
- High (1440p): 0.75 + TAAU, 6 @1024, volumetric 0.33 / 12 steps, SSGI Low (1x12), motion blur.
- Ultra (host RTX 5090 @4K): 0.67-0.75 + TAAU, 8 @2048, volumetric 0.5 / 16 steps, VXGI 128^3 or SSGI High, SSR.
- Rough per-feature GPU estimates at 1080p on a 3060-class card (low confidence; measure with renderer.resolveTimestampsAsync('render')):
- each 1024² spot shadow pass on merged geometry: 0.1-0.3 ms, plus 0.2-0.4 ms per-pixel shading per shadowed light
- GTAO half-res: 0.5-1 ms
- TRAA: about 0.3 ms
- bloom: 0.3-0.6 ms
- quarter-res volumetrics: 0.8-2 ms
- SSGI Medium: 2-4 ms
- SSR: 1-3 ms
- point-light cube shadow: 6x a spot shadow pass
- Draw-call hygiene: merge static walls/floors per room or chunk (BufferGeometryUtils.mergeGeometries); InstancedMesh for repeated props; BatchedMesh for varied props sharing one material (webgpu_mesh_batch.html); THREE.BundleGroup (render bundles: group.static, group.needsUpdate) for static chunks (webgpu_performance_renderbundle.html). Aim for under 300 main-pass draws and under 150 per shadow pass. Read renderer.info.render.drawCalls.
- Many unshadowed lamps: renderer.lighting = new DynamicLighting({ maxPointLights: 32, maxSpotLights: 16 }) works on both backends without recompiles. new ClusteredLighting(1024, 32, 24, 64) covers non-shadow point lights only and is built on compute, so assume WebGPU only. Fluorescent panels: RectAreaLight (webgpu_lights_rectarealight). Static lamp shadows: shadow.autoUpdate = false; shadow.needsUpdate = true after level generation.
- Outdoor moonlit maps: SunLight + SunLightNode (addons/lights) needs renderer.library.addLight(SunLightNode, SunLight); it has cascaded shadows (2 cascades by default in r186).
- VXGI (Ultra only): giPass = vxgi(depth, normal, scene, camera, 128); voxelize once after procedural generation; set volume.needsUpdate on changes; cones 2-4; composite with TRAA like webgpu_vxgi.html. LightProbeGrid: new LightProbeGrid(w,h,d,nx,ny,nz); scene.add(grid); grid.bake(renderer, scene, { cubemapSize: 8, bounces: 1 }).
- Rapier 0.21 API: import RAPIER from '@dimforge/rapier3d-compat'; await RAPIER.init().
- Character controller: kcc = world.createCharacterController(0.01); kcc.enableAutostep(0.4, 0.2, true); kcc.enableSnapToGround(0.3); kcc.setMaxSlopeClimbAngle(0.87); kcc.setApplyImpulsesToDynamicBodies(true); each tick kcc.computeColliderMovement(collider, desired) then kcc.computedMovement() / kcc.computedGrounded().
- Doors: world.createImpulseJoint(RAPIER.JointData.revolute(a1, a2, {x:0,y:1,z:0}), frame, door, true) + setLimits(min, max) + configureMotorPosition(0, k, c) to auto-close.
- Carrying: kinematic hand body + JointData.spring(rest, k, c, a1, a2).
- Ragdolls: JointData.spherical (hips, shoulders, neck) + revolute with limits (knees, elbows).
The same package runs in Node 24 for host-authoritative props. Deep imports changed in 0.20 (dist/), so copy code from current docs, not old tutorials.

- Character creation graphics: SkinnedMesh + morph targets (webgpu_morphtargets_face.html), SkeletonUtils retargeting (webgpu_animation_retargeting.html), skinning instancing for crowds or monsters (webgpu_skinning_instancing.html), MeshSSSNodeMaterial for monster skin (webgpu_materials_sss.html). Avoid depending on external avatar SaaS.
