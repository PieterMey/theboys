# ai-llm

## Executive summary
'JEV' is almost certainly Jev from TypeSafe AI, released in limited early access on 2026-09-15. It is a non-generative 'System One' decision model: you send a state plus typed questions (a choice of up to 255 options, a score with 2-10 levels, or a yes/no 'noul') to POST https://api.typesafe.ai/v1/systemone and get back calibrated probabilities, in a claimed 70-500 ms, for $0.042 per million input tokens with output free. One caveat: no official source documents an 'apikey_' key prefix (third-party docs show 'ts_' placeholders), so the user must confirm the key came from console.typesafe.ai; if it did not, every Jev path below falls back to Claude Haiku 4.5 with no design change. Jev cannot write text, and Claude's reasoning models are slow to the first token (Artificial Analysis median on 10K-token prompts: Haiku 4.5 0.69 s, Sonnet 5.5 low 1.05 s, Sonnet 5.5 medium 7.16 s, Opus 5.5 low 8.29 s, and Opus 5.5 thinking cannot be turned off), so the design should be 'Claude prepares, Jev decides, code rules'. Concretely: Opus 5.5 writes each mission's lore, clue notes and an entity-specific spirit-box phrase bank in the background, one mission ahead. Sonnet 5.5 at low effort returns the end-of-mission review in about 10 s. Jev (falling back to Haiku 4.5, then rules) makes the sub-second picks. Deterministic code owns every truth: codes, ritual order, evidence, spawns, and which player sees which clue fragment, which also makes teamwork mandatory. The spirit box works like this: push-to-talk Web Speech API transcription (on-device mode since Chrome 139), then a deterministic gate on whether the entity answers, then a Jev choice over a shuffled phrase bank (~0.3 s) or a Haiku 4.5 structured pick (~1 s), with the audio masked by an instant static sweep. The AI Director stays a deterministic tension model: it offers Jev only the events that pass cooldowns and samples from Jev's probabilities, so an outage only degrades it to weighted-random events. Costs are trivial: about $0.9 per hour for the whole group with this mix (about $0.60 Opus lore, $0.11 Sonnet terminal chat, $0.06 Sonnet reviews, $0.04 Jev decisions, $0.07 Haiku taunts and fallbacks), and under about $2 per hour if all real-time traffic falls back to Haiku. The real cost risk is a runaway loop, so use a dedicated Anthropic workspace with a spend limit plus an in-app per-session dollar cap. On refusals: Sonnet 5.5's general_harms classifier can decline harmless horror requests, and server-side fallback does not retry that category, while Opus 5.5 runs only cyber/bio/reasoning_extraction classifiers and Haiku 4.5 runs none. So keep the tone PG-13 dread (implied violence, no gore, no self-harm encouragement, in line with Anthropic's usage policy), never name a JSON field 'reasoning', and fall back to Haiku or templates. Player speech is hostile data: the LLM gets no authority (its phrase ids and enums are validated by code), never sees secrets, receives transcripts JSON-encoded, and detected jailbreak attempts become in-world deflections. Evidence from shipped games agrees: MIMESIS (2M+ sales) gets its scares by replaying real player voice clips chosen by small models rather than LLMs, Where Winds Meet's LLM NPCs were talked into false quest completions, and a 2026 study found that LLM NPCs raise cognitive load without significantly improving the overall experience. Recommendation for tonight: ship the server-side AI gateway (budgets, timeouts, circuit breakers, mock/replay modes); Opus 5.5 lore, clue and phrase-bank generation with code-owned secrets and a template fallback; spirit box v1 on Haiku 4.5, with Jev switched on only if a startup health check passes; a deterministic Director with an optional Jev advisor; and the Sonnet 5.5 'Company performance review'. Leave terminal chat, name/quote taunts and voice-clip mimics for later sessions.

## Recommendations
- [TONIGHT] Use the architecture 'Claude prepares, Jev decides, code rules'. All AI calls go from the Node host server through one server-side AiGateway module, and no key ever reaches a browser. -- Jev cannot generate text, and Claude reasoning models take about 1-8 s to the first token. Content can be written ahead of time, but real-time picks need sub-second latency. Keeping keys and budgets on the host also blocks key leaks and lets code enforce caps. Both SDKs have browser-use guards.
- [TONIGHT] Mission lore, clue and phrase-bank generator on claude-opus-5-5 (effort low, structured output via messages.parse + zodOutputFormat, system prompt cached with a 1h TTL), prefetched one mission ahead. Code generates every secret and checks that each one appears verbatim; a handcrafted template pack is the fallback. -- This content is not latency-critical (40-90 s is fine in the background) and quality matters. Opus 5.5 does not run the general_harms classifier, so it is less likely to decline horror prose. About $0.12 per mission. Code-owned secrets avoid the 'LLM decides game state' failure seen in Where Winds Meet.
- [TONIGHT] Spirit box v1: push-to-talk, then Web Speech API (processLocally when on-device is installed; typed fallback for Firefox), then a deterministic answer gate, then a claude-haiku-4-5 structured phrase-id pick (2.5 s hard timeout, maxRetries 0), then phrase audio over an instant static sweep. -- Haiku 4.5 is the fastest Claude model (0.69 s median to the first token on Artificial Analysis), runs no classifier refusals, and costs about $0.32/h at 150 questions. A phrase bank means the entity can never say anything unvetted, and the static masks the remaining latency.
- [TONIGHT] Enable Jev (pin jev-1.13.0) as the primary real-time picker for spirit-box replies and Director events only after a startup health check passes (client.models.list() / GET https://api.typesafe.ai/v1/models, with the user's consent). Otherwise the JEV_ENABLED flag stays off. -- Uses the key the user asked to include, in the one role a decision model is best at (choosing from 255 or fewer options with calibrated probabilities in about 70-500 ms, at about $0.04/h). The early-access status and the unverified key prefix make it unsafe as a hard dependency.
- [TONIGHT] AI Director: a deterministic tension curve (build-up, peak, relief) plus cooldown and legality filters produce allowed_events every 20-30 s. Jev (or a Haiku fallback) only chooses among those, and code samples from the returned probabilities and enforces a scare budget. -- Pacing quality and fairness stay deterministic and testable. The model only biases choices, so an outage degrades to weighted random with no visible failure.
- [TONIGHT] End-of-mission 'Company performance review' on claude-sonnet-5-5 (effort low, structured output), started at the mission-end trigger. A mad-libs template shows if the review is not ready in 12 s, and a late AI memo is swapped in when it arrives. A config toggle switches to Opus 5.5. -- High comedic payoff with zero gameplay risk. Sonnet 5.5 low gives about 1 s to the first token and about 100 tokens/s, so a review takes about 10 s, against roughly 20-30 s on Opus 5.5 low. About $0.014 per review.
- [TONIGHT] Shared tone and safety layer: a PG-13 'dread, not gore' style guide in every system prompt, output wordlist/PII filter, refusal handling (stop_reason 'refusal' leads to a Haiku 4.5 retry, then a template), no JSON fields named reasoning/thinking/trace, and a one-line AI disclosure in the lobby. -- Anthropic's AUP bans graphic violence, gratuitous gore and glamorized self-harm, and requires AI disclosure for chatbots. The Sonnet 5.5 general_harms category can fire on harmless work and is not retried server-side. Fields like 'reasoning' trigger billed reasoning_extraction refusals.
- [TONIGHT] Prompt-injection stance: the LLM has zero authority (only enums/ids validated by code), secrets are never in any prompt, transcripts and names are JSON-encoded data, meta/jailbreak utterances get in-world deflections, players have per-player token buckets, and repeat offenders get hunted instead of answered. -- Friends will try 'ignore your instructions'. Anthropic recommends screens, JSON-encoding, least privilege and throttling, and the Jev docs admit it can be steered by injected text. Making attacks harmless and part of the game beats trying to make them impossible.
- [TONIGHT] Cost controls: a dedicated Anthropic workspace and API key for the game with a monthly spend limit (e.g. $25), AI_SESSION_BUDGET_USD=3 enforced from response.usage, per-feature caps, a circuit breaker, and a logs/ai-usage.jsonl log. -- Normal use is about $0.9/h, so only bugs can cost real money. Spend limits cannot be set on the Default workspace. A spend-limit hit returns 400 or 429 and must turn AI features off gracefully.

The real latency from the user's PC (possibly in the EU) must be measured, because Artificial Analysis numbers use 10K-token prompts from the US.
- [later] Terminal chat with 'the Company': a deterministic command parser first, and free text only to claude-sonnet-5-5 (thinking between_tools or effort low, streamed typewriter). Read-only facts arrive via mid-conversation system messages, and no tool can change game state. -- Lethal Company-style flavor at about $0.11/h. Sonnet 5.5 holds a system-prompt persona well, but it adds surface area and was not needed for the first night.
- [later] Entity taunts and whispers that use player names and short quotes from opt-in transcripts (Haiku 4.5, generated off the critical path in calm periods, filtered, queued with a 3-min TTL, used by the Director's whisper event). -- Very scary and cheap (about $0.02/h), but it needs every player's speech-to-text, consent, and robust filtering of slurs and personal info.

No voice cloning and no LLM speech. -- The best-selling AI co-op horror game (MIMESIS, 2M+ copies) replays recorded audio rather than synthesizing it, both for privacy and because 'a 2-second illusion creates long distrust'. - [later] Between-session content: Opus 5.5 obituaries, personnel files and a session 'case file' recap that persist into future procedurally generated notes; the Batch API (50% off: Opus 5.5 $2/$10) pre-generates a contract library overnight. -- Feeds progression and continuity cheaply, with no latency constraint at all.

## Risks
- JEV was misidentified, the key is invalid or belongs to another provider, or TypeSafe early access proves unstable (signups paused, rate limits 'adjusting dynamically', 529 Overloaded). => Health check at boot with the user's consent; feature flag JEV_ENABLED=auto; 1.5 s timeout; circuit breaker; Claude Haiku 4.5 fallback, then deterministic rules. No feature depends on Jev.
- Claude latency spikes or an outage during play. => Hard timeout on every route (spirit box 2.5 s, director 1.5 s, review 25 s, lore 180 s); maxRetries 0 on real-time routes; static or audio masking; prefetched content; template packs; circuit breakers that fall back silently so immersion holds.
- Opus 5.5 cannot disable thinking, and even at low effort the median time to first token is about 8 s, so it blows the 1-2 s budget if used on interactive paths. => Route by latency: Opus 5.5 only on background or async paths, Sonnet 5.5 (low or between_tools) for chat and reviews, Haiku 4.5 or Jev for anything under 2 s. Model ids come from env config.
- Safety-classifier refusals on horror content: Sonnet 5.5 general_harms fires on harmless work and is not retried server-side; reasoning_extraction refusals are billed. => PG-13 'dread, not gore' tone guide; no reasoning-type fields; check stop_reason; retry on Haiku 4.5 (no classifiers), then a template; log refusal categories to tune prompts.
- Prompt injection and griefing through player speech or character names (extracting codes, breaking character, making the entity say offensive things). => The model has zero authority; secrets are never in the prompt; transcripts and names are JSON-encoded; outputs are restricted to enums or phrase ids; Jev or Haiku detection of meta and jailbreak attempts produces in-world deflections; per-player rate limits; the persona is reinforced in the system prompt.
- Offensive or unsafe outputs, especially taunts that quote players or use their names. => Opt-in only; wordlist and PII regex filters on both input snippets and outputs; optional Jev output battery (TypeSafe guardrail cookbook pattern); cap length and frequency; never echo raw user text unfiltered.
- LLM-written clues contradict code-owned solutions (wrong code, wrong ritual order). => Code generates every secret and fragment; the LLM only wraps given fragments; verbatim inclusion is validated; one retry with the errors; then the template pack.
- Cost runaway from a bug (e.g. a call per frame or a retry loop). => In-app per-session dollar cap computed from usage; per-feature token buckets; concurrency of 1 per feature per player; usage JSONL log; dedicated workspace spend limit; spend-limit 400/429 responses switch AI features off gracefully.
- Structured-output first-call grammar compile latency, or a 400 'Schema is too complex for compilation'. => Small static schemas (24 or fewer optional fields, no unions); warm-up request at boot; validate dynamic ids in code; the ai:smoke script compiles every schema before a session.
- API key leakage through the browser bundle, logs or git. => Keys only in the host's .env (gitignored), loaded via --env-file; never sent to clients; dangerouslyAllowBrowser never set; logs redact authorization headers; the Jev key is passed explicitly from JEV_API_KEY.
- Privacy: voice audio and transcripts go to Google (Chrome cloud speech-to-text by default), Anthropic and TypeSafe. => Consent screen in the lobby; push-to-talk only; processLocally on-device recognition when available; transcripts held in RAM for the session only; quote features opt-in.
- Firefox, or browsers without SpeechRecognition, cannot use the spirit box by voice. => Typed-question fallback tonight; later, host-side Whisper or Parakeet on the RTX 5090 fed by push-to-talk clips.
- Jev quirks: first-option bias, literal reading, context rot, steerable by adversarial text. => Shuffle options on every call; precise one-line criteria; compact relevant state; confidence gating; treat Jev outputs as advisory picks among pre-approved options only.
- Repetitive content across missions (same names, same phrasing). => Theme seeds from a large list; exclusion lists of names and phrases already used, kept on disk; vary archetypes from a code table; store generated content history.
- LLM-heavy interaction raises cognitive load and lowers usability (2026 study). => Keep AI interactions short, optional and diegetic; the core sneak, objective and extract loop stays deterministic; 1-5 word spirit replies; reviews shown only between missions.
- API 400s from outdated parameter habits: temperature/top_p on Opus or Sonnet 5.5, disabled thinking, prefill, forced tool_choice, effort on Haiku 4.5. => Follow the per-model rules in the implementation notes; the integration smoke test covers every route and model before the session.

## Decision-critical claims
- JEV_API_KEY is a TypeSafe AI Jev key (a decision model that returns probabilities over typed questions and cannot generate text). If wrong, the Jev paths go to Haiku 4.5; if JEV turns out to be a text LLM, it could instead serve lore or chat.
- Jev's real latency from the host PC is at most about 500 ms at p95 (vendor claim 70-500 ms; demo 227 ms average / 400 ms p95 from US-East). If it is much slower from the user's location, Haiku 4.5 becomes the primary spirit-box and Director picker.
- Claude median time to first token on 10K-token prompts (Artificial Analysis): Haiku 4.5 0.69 s, Sonnet 5.5 low 1.05 s, Sonnet 5.5 medium 7.16 s, Opus 5.5 low 8.29 s. This sets the model routing (no Opus on any path under 5 s).
- Opus 5.5 thinking cannot be disabled (400); Sonnet 5.5 can run without up-front thinking via thinking {type:'between_tools'} at effort high or below; Haiku 4.5 has no thinking by default and does not accept effort.
- Sonnet 5.5's general_harms classifier can decline harmless requests and is not retried by server-side fallback, while Haiku 4.5 runs no safety classifiers. This drives the refusal-fallback chain for horror content.
- Structured outputs (output_config.format) work on Haiku 4.5, Sonnet 5.5 and Opus 5.5, with limits of 24 optional parameters and 16 union-typed parameters, no min/max constraints, and a grammar cached 24 h.
- The whole AI layer costs about $0.9 per hour for the group, and under about $2 per hour if everything falls back to Haiku. Model choice can therefore follow quality and latency rather than cost.
- Spend limits cannot be set on the Default Anthropic workspace, so a hard cap needs a dedicated workspace and key; hitting a user-set limit returns HTTP 400.
- Chrome 139+ offers on-device Web Speech recognition (processLocally), while Chrome's default recognition is server-based and SpeechRecognition is not Baseline (no Firefox support). This affects the speech-to-text plan and the consent text.
